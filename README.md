# Publishing this portfolio on GitHub Pages

1. Create a new GitHub repo named `<your-username>.github.io` (e.g. `justinleong.github.io`). Using this exact name gives you a clean URL; any other repo name works too, just under a `/repo-name/` path.
2. Upload `index.html` to the root of the repo (drag-and-drop on github.com works, or `git add / commit / push`).
3. Go to repo **Settings → Pages**, set source to the `main` branch, root folder, and save.
4. Your site goes live at `https://<your-username>.github.io` (or `.github.io/repo-name`) within a minute or two.

## Before you publish

- Swap the placeholder `GitHub` link in the header for your actual GitHub profile URL.
- Double check you're comfortable with your phone number being public — you can remove it and keep just email + LinkedIn if not.
- Optional: replace the `#` GitHub link icon, add a favicon, or swap the accent color (`--accent` in the `<style>` block) if green isn't your preference.

## For the interview

Pull this up on your phone or laptop and reference it when you're asked about skills, experience, or "tell me about yourself" — that's what earns the portfolio-usage marks on the rubric. Walk the panel through one card (e.g. the internship) rather than reading the whole page at them.
